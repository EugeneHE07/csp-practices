# 2026-11-03 算法与函数总结

## 1. `2.2.2_202109.cpp`

### 核心算法

程序计算一组数的总和，并根据相邻元素的大小关系计算另一个结果：

- `Smax`：累加所有输入数据。
- `Smin`：当当前元素大于前一个元素时，累加当前元素。

本质上是一次线性扫描和相邻元素比较。

### 关键函数和语句

- `cin`：读取输入数据。
- `cout`：输出结果。
- `if (B[i - 1] < B[i])`：判断相邻元素的大小关系。

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 注意点

代码中数组下标存在越界问题。数组下标最大只能到 `n - 1`，但输入循环访问了 `B[n]`。此外，`int B[n]` 是变长数组写法，并非标准 C++，建议改用 `vector<int>`。

## 2. `2.3.1_202104.cpp`

### 核心算法

使用计数数组统计二维数组中每个数值出现的次数。读取每个元素时执行：

```cpp
h[A[i][j]]++;
```

最后依次输出 `0` 到 `L - 1` 各个数值的出现次数。

### 关键数据结构和函数

- `A[n][m]`：保存输入的二维数组。
- `h[L]`：计数数组，用于统计各个数值出现的次数。
- `cin`、`cout`：完成输入和输出。

### 复杂度

设二维数组共有 `n × m` 个元素：

- 时间复杂度：`O(nm + L)`
- 空间复杂度：`O(nm + L)`

## 3. `2.3.2_201909.cpp`

### 核心算法

程序读取 `N` 个对象及其 `M` 项数据：

1. 计算每个对象的额外数据总和 `num[i]`。
2. 计算所有对象的总值 `T`。
3. 找出 `num[i]` 最小的对象，并输出其编号。

其中通过比较 `-num[i]` 来寻找 `num[i]` 的最小值。

### 关键函数和语句

- `num[i] += t`：累加每个对象的多项数据。
- `T += a[i] + num[i]`：计算总值。
- `if (0 - num[i] > P)`：寻找最小的 `num[i]`。

### 复杂度

- 时间复杂度：`O(NM)`
- 空间复杂度：`O(N)`

### 注意点

若多个对象的 `num[i]` 相同，程序保留编号最小的对象，因为只有在严格变小时才更新结果。

## 4. `2.4.2_202406.cpp`

### 核心算法

程序将一个 `n × m` 的二维数组按行优先顺序展开，再重新填充到 `p × q` 的二维数组中。

先将原位置转换为一维下标：

```cpp
int temp = i * m + j;
```

再将一维下标转换为目标数组的行列位置：

```cpp
int new_i = temp / q;
int new_j = temp % q;
```

这是典型的一维下标与二维坐标之间的转换。

### 关键数据结构和函数

- `a[n][m]`：原二维数组。
- `vector<vector<int>> b`：目标二维数组。
- `/` 和 `%`：分别用于计算目标行号和列号。

### 复杂度

设元素总数为 `n × m`：

- 时间复杂度：`O(nm + pq)`
- 空间复杂度：`O(nm + pq)`

### 注意点

应保证 `n × m = p × q`，否则重新排列时可能出现数据不完整或越界。

## 5. `2.4.4_2-14map.cpp`

### 核心算法

程序使用 `map` 统计元素出现的次数：

```cpp
cnt[A[i]]++;
```

`map` 会按照键的升序自动维护元素，因此遍历时可以按升序输出不同元素及其出现次数。

### 关键数据结构和函数

- `vector<int>`：保存输入序列。
- `map`：保存元素和出现次数的映射。
- `cnt[A[i]]++`：完成频次统计。
- `begin()`、`end()`：遍历映射中的元素。

### 复杂度

使用 `map` 时，每次插入或查找的复杂度为 `O(log n)`：

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`

### 注意点

代码中定义的是：

```cpp
map<string, int> cnt;
```

但数组 `A` 的元素类型是 `int`。应将其改为：

```cpp
map<int, int> cnt;
```

## 6. `2.4.5(2)_201912.cpp`

### 核心算法

程序使用嵌套映射保存二维坐标：

```cpp
map<int, map<int, bool>> A;
```

外层键表示横坐标，内层键表示纵坐标，用于判断某个坐标是否存在。

程序对每个点检查周围 8 个方向：

- 前 4 个方向：上、下、左、右。
- 后 4 个方向：左上、右上、左下、右下。

只有当上下左右 4 个方向均存在点时，才按照对角线相邻点的数量进行统计。

### 关键数据结构和函数

- `map<int, map<int, bool>>`：保存二维坐标。
- `count()`：判断指定坐标是否存在。
- `dx[]`、`dy[]`：表示 8 个方向的坐标变化。
- `ans[]`：统计不同对角线邻居数量的点数。

### 复杂度

- 时间复杂度：约为 `O(n log n)`
- 空间复杂度：`O(n)`

## 7. `2.4.5_201912.cpp`

### 核心算法

程序使用：

```cpp
map<pair<int, int>, bool> A;
```

将二维坐标组合成 `pair<int, int>` 作为键，从而直接判断某个坐标是否存在。

对每个坐标检查周围 8 个方向：

- 前 4 个方向表示上下左右。
- 后 4 个方向表示四个对角线方向。

当一个点的上下左右 4 个位置都存在时，根据其对角线邻居数量进行分类统计。

### 关键数据结构和函数

- `pair<int, int>`：表示一个二维坐标。
- `map<pair<int, int>, bool>`：保存所有坐标。
- `A.count(pos)`：判断坐标是否存在。
- `dx[]`、`dy[]`：表示 8 个方向。
- `ans[5]`：统计对角线邻居数量为 `0` 到 `4` 的点数。

### 复杂度

- 时间复杂度：约为 `O(n log n)`
- 空间复杂度：`O(n)`
